# マッスルラボ — 鍛えた部位がそのまま育つ、分身の育成ゲーム

培養カプセルの中にいる自分の「分身」を、毎日の筋トレで育てるアプリ。開くとその日の筋トレメニュー（今日の実験）と食事の目安が出て、やった分だけ、鍛えた部位が目に見えて太くなる。休む日も「回復日」として記録でき、連続日数は続く。

## 使い方（1日の流れ）

1. 開くと「今日の実験」が出る。筋トレ 3〜7 種目（1回の時間の設定が 10分なら3種目、20分なら5種目、30分なら7種目）
2. 「実験を始める」を押し、1セット終えるごとに「セット完了」。休憩のタイマーが自動で始まる
3. 全部終えたら、負荷の感想（楽だった / ちょうどいい / きつかった）を答える。次回の回数が自動で変わる
4. 鍛えた部位に経験値が入り、分身のその部位が太くなる。レベルが上がると新しい種目が解放される
5. 「食事」タブで、その日の食事の目安と例を見る。食べたら「食べた」を押すと栄養チャージがたまり、その日の経験値に最大 +50% のボーナスがつく
6. メニューが出ない日は「回復日」。「回復を記録する」を押すと、連続日数が続く

## しくみ

| 項目 | 内容 |
|---|---|
| 部位 | 胸・背中・脚・腹・肩・腕 の6つ。部位ごとにレベルがあり、分身の体型に反映される |
| 回復 | 鍛えた部位は「回復中」になり、2日（腹は1日）たつまでメニューに入らない。ホームでは回復中の部位がオレンジ色に光る |
| メニューの自動提案 | 回復が済んだ部位のうち、長く鍛えていない部位から選ぶ。種目は、器具の設定と部位のレベルで決まる（全103種目: 自重49・ダンベル27・ジム27） |
| 実験の日と回復日 | 「週に実験する日数」（2〜6日）の設定から自動で決まる。その日の気分で「今日は休む」「それでも実験する」に切り替えられる |
| 食事の目安 | 性別・年齢・身長・体重と目的から、1日のカロリーと、たんぱく質・脂質・炭水化物を計算。朝・昼・夜・間食ごとに、自炊 / コンビニ / 外食 の例（全69例）を出す |
| 研究ランク | 実験・回復の記録・食事の記録・研究発表で研究ポイント（RP）がたまり、見習い研究員から名誉所長まで8段階。上がると培養液の色とカプセルの土台が変わる |
| 研究発表 | 毎週月曜に、前の週の成果を S〜C で判定（実験の回数・記録した日・食事の記録・鍛えた部位の数） |
| 記録 | 部位のバランス（レーダーチャート）、カレンダー、体重の推移、研究発表の履歴、種目図鑑 |

数値や計算式の細かい内容は [docs/20261119_DOC_0001_ALL_現状の仕様と構成.md](docs/20261119_DOC_0001_ALL_現状の仕様と構成.md) に書いてある。

## 注意して作ってある点

- **食事と筋トレの内容は「目安」と明記している。** 診断や治療の代わりにはならないこと、持病のある人・妊娠中の人は医師に相談することを、食事タブ・計算のしかた・設定に書いてある
- しぼる目的でも、カロリーは基礎代謝を下回らない。18歳未満は減らす調整をしない
- 痛みを感じたら中止すること、家具を鉄棒の代わりにしないことなどを、種目の説明に入れてある
- 合わない種目は「入れ替え」や「メニューに出さない」で外せる

## ファイル構成

```
マッスルラボ/
  index.html          アプリ本体（HTML / CSS / JS を1ファイルに）
  manifest.json       PWA の設定（名前・色・アイコン・縦向き固定）
  sw.js               Service Worker（本体とアイコンを保存して、オフラインで開く）
  icon.svg            アイコンの元データ（フラスコの中のダンベル）
  icon-192.png / icon-512.png / apple-touch-icon.png   icon.svg から作ったアイコン
  README.md           このファイル
  docs/               開発ドキュメント（ルールは docs/README.md）
  tools/
    check.mjs         ルール部分の自動チェック（node tools/check.mjs）
    make-artifact.sh  Claude Artifact に載せる版を作る
    make-icons.sh     icon.svg から PNG を作り直す
  .claude/            Claude 用の設定（ドキュメント規則、ローカル確認用サーバの設定）
```

## ローカルで動かす

```bash
python3 -m http.server 8821 --bind 127.0.0.1
```

を `マッスルラボ/` で実行して http://localhost:8821/ を開く。Service Worker はこの http サーバ経由でだけ動く（ファイルを直接開いた場合と Claude Artifact では登録しない）。

`?debug=1` を付けると `window.__mlab` が使える（動作確認用）。日付を進める `__mlab.shiftDays(1)`、今日の実験を全部やったことにする `__mlab.simulate('ok')` など。

## 変更したときの確認

```bash
node tools/check.mjs
```

画面を使わずに、メニュー作り・回復・レベル・食事の目安・研究発表を、設定の全組み合わせ（135通り × 77日ぶん）で確かめる。2026-11-19 時点で PASS 207,856 項目。

本体（`index.html`）は、次に開いたときに自動で新しい版に入れ替わる（`sw.js` の作り）。`sw.js` が先に保存するファイルの一覧を変えたときだけ、`sw.js` の `CACHE` の番号を上げる。

## Claude Artifact に載せる

Artifact は `<html>` や `<head>` を自動で付けるので、`index.html` をそのまま載せず、印（`@artifact-start` 〜 `@artifact-end`）の間だけを抜き出した版を作って載せる。

```bash
bash tools/make-artifact.sh 出力先.html
```
