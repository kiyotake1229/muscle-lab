# 同じドメインのほかのアプリのオフライン用キャッシュを消してしまう不具合

- 管理番号: #0003
- 種類: BUG（バグ修正）
- 対象: PWA（`sw.js`）
- 作成日: 2026-11-19
- 関連: #0002（GitHub Pages で公開）。同じ問題の前例: `思考力/docs/20261009_BUG_0013_PWA_ほかのアプリにキャッシュを消されても入れ直す.md`

## 概要

GitHub Pages に公開した直後の確認（#0002）で、マッスルラボの Service Worker が、同じドメイン（`kiyotake1229.github.io`）に載っているほかのアプリのオフライン用キャッシュを消してしまうことが分かった。ブラウザのキャッシュの置き場所（Cache Storage）はドメインごとに1つで、全アプリが共有しているのに、古い版を消す処理が「自分の今の版以外を全部消す」書き方になっていたため。消すのを自分のキャッシュだけにし、あわせて、ほかのアプリに自分のキャッシュを消されても入れ直すようにした。

## 対象ファイル

- `sw.js`

## 原因

`sw.js` の activate が次の書き方だった（兄弟アプリの `sw.js` を手本にしたもの）。

```js
caches.keys().then(ks=>Promise.all(ks.filter(k=>k!==CACHE).map(k=>caches.delete(k))))
```

ローカル（`localhost:8821`）ではこのアプリしか無いので問題が出ない。GitHub Pages では、コツコツ（`kotsu-…`）など、同じドメインのほかのアプリのキャッシュも `ks` に入り、まとめて消える。消されたアプリは、次に通信なしで開いたときに表示できなくなる。

## 変更内容

### 1. 消すのは自分のキャッシュだけ

キャッシュ名を `musclelab-` で始めることにし（`PREFIX`）、activate で消すのは「`musclelab-` で始まり、今の版ではないもの」だけにした。

### 2. このアプリの外の要求には触らない

fetch で、要求先が Service Worker の範囲（`/muscle-lab/`）の外なら何もしない。

### 3. ほかのアプリに消されても入れ直す（refill）

同じドメインのほかのアプリには、まだ「自分以外を全部消す」書き方のものがある（下の「残っていること」）。それらを開くと、マッスルラボのキャッシュが消される。そこで、ページを開くたびに（つながっているとき）、先に保存するファイル7件（`./`・`index.html`・`manifest.json`・`icon.svg`・アイコン3つ）のうち無くなったものだけを取り直す。表示は待たせない。

消された直後に通信なしで開いた場合は防げない。一度つながった状態で開けば元に戻る。

### 4. そのほか

- 先に保存するファイルは、HTTP のキャッシュを通さずに取る（`cache: 'reload'`）
- 転送された応答と、同じドメイン以外の応答は保存しない
- キャッシュ名を `musclelab-v4` に上げた（`sw.js` の説明も書き直した）

## 確認

ローカル（http://localhost:8821/ 。Claude の内蔵ブラウザ）で、2026-11-19 に確認した。

- Service Worker の登録を外し、ほかのアプリのつもりのキャッシュ `kotsu-v6-test` と、自分の古い版のつもりの `musclelab-v1-old` を作ってから開き直す → `kotsu-v6-test` は残り、`musclelab-v1-old` は消え、`musclelab-v4` に7件が入った
- `musclelab-v4` を丸ごと消して（ほかのアプリに消されたのと同じ状態）、つながった状態で開き直す → 7件が戻った
- サーバを止めた状態で開き直す → キャッシュからアプリが表示された。キャッシュに無いファイルの要求は失敗として返る（アプリの本体を代わりに返さない）
- 公開URLでも、反映後に同じ確認を行った。結果は下の「公開URLでの確認」

## 公開URLでの確認

修正を push（コミット `0d4922a`）して反映されたあと、公開URL（https://kiyotake1229.github.io/muscle-lab/ ）を Claude の内蔵ブラウザで開いて、2026-11-19 に確認した。

- 公開されている `sw.js` が修正後の内容（`musclelab-v4`、消すのは `musclelab-` で始まるものだけ）になっている
- マッスルラボの Service Worker の登録だけを外し、ほかのアプリのつもりのキャッシュ `zz-other-app-test` と、自分の古い版のつもりの `musclelab-v1-old` を作ってから開き直す → `zz-other-app-test` は残り、`musclelab-v1-old` は消え、`musclelab-v4` に7件（`/muscle-lab/`・`index.html`・`manifest.json`・`icon.svg`・アイコン3つ）が入った。確認用のキャッシュはこのあと消した
- 同じドメインのほかのアプリ12本の Service Worker の登録には触れていない（確認の前後で一覧が同じ）
- アプリは表示され、保存してあった記録も残っている。エラーなし

修正前の版（`musclelab-v3`）が公開されていたのは、2026-11-19 の公開から修正の反映までの短い間で、その間に公開URLを開いたのは確認に使った内蔵ブラウザだけ。この内蔵ブラウザの中では、修正前の版がほかのアプリのキャッシュを消した可能性がある（清武や利用者の端末には影響しない。内蔵ブラウザでそれぞれのアプリをつながった状態で開けば、アプリごとの作りに応じて入り直す）。

## 残っていること（このアプリの外）

同じドメインの兄弟アプリのうち、次のものは今も「自分以外のキャッシュを全部消す」書き方になっている（2026-11-19 に各フォルダの `sw.js` を確認）。開かれるたびに、マッスルラボを含むほかのアプリのキャッシュを消す。

`habit/`・`ブロックゲーム/`・`mahjong/`・`動画編集/`・`語彙力/`・`タイピングゲーム/`・`土地開拓ゲーム/`・`自己開発/そなえ帳/`・`録音と対話/`・`リラックス/`・`あなたのアプリ/`・`マッチングアプリ/`

根本の直し方は、それぞれの activate を「自分の名前で始まるキャッシュだけを消す」形にそろえること。ほかのプロジェクトの変更と公開になるので、この文書の作業には含めていない。
