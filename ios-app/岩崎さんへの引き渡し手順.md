## 3. ビルド手順

このフォルダ（`ios-app/`）で、以下を順に実行してください。

```bash
# 1) 依存パッケージを取得（Dropbox を軽くするため node_modules は置いていません）
npm install

# 2) アプリ本体を同梱し、iOS 用の部品を取り込む（中で pod install が動きます。Xcode が必要）
npm run sync

# 3) Xcodeで開く
open ios/App/App.xcworkspace
```

> **注意**: 必ず `App.xcworkspace` を開いてください（`App.xcodeproj` ではありません）。

`npm install` でできる `node_modules/` は約100MBあります。Dropbox の同期が重くなるので、作業が終わったら消して構いません（次に使うときに `npm install` で戻ります）。

### Xcode上での設定

1. 左ペインで **App** を選択 → **Signing & Capabilities** タブ
2. **Team** に自社のApple Developerアカウントを選択（"Automatically manage signing" はON）
3. 必要に応じて **Bundle Identifier** を自社のものに変更
4. **General** タブで **Version**（1.0.0）と **Build**（1）を確認

Capability（機能の追加）は何も要りません。通知は端末の中だけで予約するローカル通知なので、Push Notifications の Capability は不要です。

### 動作確認

上部のデバイス選択から実機またはシミュレータを選び ▶ で起動。次の点を見てください。

- 起動画面（紺の地にフラスコの絵）のあと、はじめての設定（「はじめる」の画面）が出る
- 上のステータスバー（時刻・電池）の文字が白で見える
- iPhone では縦向きのまま回転しない
- はじめての設定を終えると、ホーム（ラボ）に「今日の実験」が出る。「実験を始める」→「セット完了」で進む
- セット完了・休憩の終わり・実験の完了で振動する（**実機のみ**。シミュレータでは振動しません）
- 名前の入力（はじめての設定の最後と、設定の一番上）で出るキーボードが暗い色で出る。キーボードを閉じたあと、画面の位置がずれたままにならない
- iPad では、画面の中央に iPhone と同じ幅で表示される（縦横どちらでも崩れない）
- **お知らせ**: 右上の歯車（設定）を開き、下のほうの「お知らせ」→「実験の時間のお知らせ」を ON にする
  - 初めてのときだけ、通知の許可を求めるダイアログが**日本語で**出る。許可すると ON になり、「お知らせの時刻」が出る
  - 時刻は −／＋ で変える（1回押すと5分、押しつづけると30分ずつ）。**今より数分先**に合わせてホームに戻ると、その時刻に通知が届く（アプリを閉じていても届きます）。文面は「実験の時間です」と、その日のメニュー（部位・種目数・およその時間）。回復日は「今日は回復日です」になります
  - **その日の実験を始めたあとと、記録を済ませたあとは、その日のぶんは届きません**（確かめるときは、実験を始める前に時刻を合わせてください）
  - 端末の時刻を進めても、通知は早く届きません（「今から何分後」で予約しているため）。数分待ってください
  - 許可しなかった場合は、ON にならず「通知が許可されていません…」の案内が出る
- **記録の控え**: ふだんは見えない機能です。記録は端末の中の2か所に保存してあり、片方（WebView の保存領域）が消えたときに、もう片方から自動で戻します。アプリを入れ直した場合は両方とも消えるので、戻りません

## 4. App Store申請

1. Xcode: **Product → Archive**
2. Organizerが開いたら **Distribute App → App Store Connect** でアップロード
3. [App Store Connect](https://appstoreconnect.apple.com) でアプリ情報を入力して審査提出

### 申請情報（下書き）

**アプリ名**
```
マッスルラボ - 分身が育つ筋トレ
```

**サブタイトル（30字以内）**
```
鍛えた部位が育つ、毎日の筋トレメニュー
```

**説明文**
```
マッスルラボは、毎日の筋トレで自分の「分身」を育てるアプリです。開くとその日の筋トレメニューと食事の目安が出て、やった分だけ、鍛えた部位が目に見えて太くなります。

■ 今日のメニューが自動で出る
器具（自重・ダンベル・ジム）と1回の時間（10・20・30分）を選ぶだけ。全103種目の中から、回復が済んだ部位を選んでメニューを作ります。回数は「楽だった・ちょうどいい・きつかった」の感想から、次回に自動で調整します。

■ 鍛えた部位が、そのまま育つ
胸・背中・脚・腹・肩・腕の6つの部位にレベルがあり、培養カプセルの中の分身の体つきに反映されます。レベルが上がると、新しい種目が解放されます。

■ 休む日も記録になる
鍛えた部位は2日ほど「回復中」になり、その間はメニューに入りません。メニューが出ない日は「回復日」。回復を記録すれば、連続日数は続きます。

■ 食事の目安と例
性別・年齢・身長・体重と目的から、1日のカロリーと、たんぱく質・脂質・炭水化物の目安を計算。朝・昼・夜・間食ごとに、自炊・コンビニ・外食の例（全69例）を出します。食べたら記録すると、その日の経験値にボーナスがつきます。

■ 続けたくなる仕掛け
連続日数、8段階の研究ランク、毎週月曜の「研究発表」（1週間の成果を S〜C で判定）。部位のバランス、カレンダー、体重の推移も見られます。

■ 実験の時間のお知らせ
設定した時刻に、その日のメニューを通知でお知らせします（ON/OFF 自由。初期設定は OFF）。

■ 安心して使える
アカウント登録・広告・課金はありません。完全オフライン動作。データは端末内にのみ保存され、外部に送信されません。

※ トレーニングと食事の内容は一般的な目安です。病気の診断や治療の代わりにはなりません。持病やけがのある方、妊娠中の方は、医師に相談のうえでご利用ください。
```

**キーワード（100字以内・カンマ区切り）**

トレーニング,ダイエット,自重,宅トレ,ダンベル,ジム,食事,カロリー,たんぱく質,筋肉,フィットネス,育成,習慣,運動,ワークアウト

### プライバシー情報（App Store Connect「App のプライバシー」）

- **データを収集しません** を選択してください。
- 理由: 本アプリは通信機能を持たず、すべてのデータは端末内にのみ保存されます。アナリティクス・広告・トラッキングは一切ありません。はじめての設定で入力する性別・年齢・身長・体重も、食事の目安の計算に使うだけで、端末の外には出ません（Apple の定義では、端末の外に送らないデータは「収集」に当たりません）。
- アプリにはプライバシーマニフェスト（`ios/App/App/PrivacyInfo.xcprivacy`）を入れてあります。内容は「トラッキングなし・収集データなし」と、端末内の保存に使う機能の利用理由（UserDefaults: アプリ自身のデータの保存）です。あわせて `Info.plist` に「暗号化を使っていない」（`ITSAppUsesNonExemptEncryption = NO`）を設定済みのため、アップロードのたびの暗号化（輸出コンプライアンス）の質問は出ません
- HealthKit（ヘルスケアのデータ）は使っていません

## 5. 審査で見られやすい点

Appleガイドライン **4.2（最低限の機能）** について、本アプリは以下を満たしています。申請時の備考欄に記載すると安全です（4章の審査メモに入れてあります）。

- 完全オフラインで動作する自立したアプリ（Webサイトの単なる表示ではない）
- 端末内にデータを保存し、継続的に利用する設計（部位ごとのレベル、連続日数、研究ランク、週ごとの研究発表、体重の記録）
- ネイティブ機能として、ローカル通知（実験の時間のお知らせ）と触覚フィードバック（Haptics）を実装

ガイドライン **1.4.1（身体的な危害・健康に関する情報）** について:

- 筋トレと食事の内容は「一般的な目安」で、診断や治療の代わりにならないこと、持病のある方・妊娠中の方は医師に相談することを、アプリの中（食事タブ・「計算のしかた」・設定）と、説明文・審査メモに書いてあります
- 端末のセンサーで体の数値を測る機能はありません（Apple が認めていない種類の機能には当たりません）
- 計算の根拠（基礎代謝は Mifflin-St Jeor の式）は「計算のしかた」に書いてあります。**審査から「健康に関する情報の出典（参考文献）を示してください」と求められた場合は、清武へ連絡してください**（アプリの中に出典を足して出し直します）

ガイドライン **4.5.4（プッシュ通知の決まり）** について（このアプリはローカル通知ですが、同じ考え方で作ってあります）:

- 通知は初期値が OFF で、利用者が ON にしたときだけ許可を求めます。通知を使わなくても、アプリのすべての機能が使えます。宣伝の通知は出しません

ガイドライン **5.1.1（プライバシー）** について:

- アプリの中からプライバシーポリシーを開くリンクが必要です。**まだ入っていません**（4章の「URL」のとおり、ページの公開と合わせて清武が足します）

## 6. アプリ内容を修正したい場合

アプリ本体は 1つ上のフォルダの `index.html` です。修正後、このフォルダで：

```bash
npm run sync
```

を実行するとiOSプロジェクトに反映されます。その後Xcodeで再ビルドしてください。
2回目以降の申請では、Xcode の **General** で **Build** の数字を1つ上げてください（Version を上げる場合は Build を 1 に戻してもかまいません）。

アイコンや起動画面を変える場合は、1つ上のフォルダの `icon.svg` を直してから、次を実行します。

```bash
# 1つ上のフォルダ（マッスルラボ/）で
bash tools/make-icons.sh
# このフォルダ（ios-app/）で
npm run icons
```

`npm run icons` のあと、`ios/App/App/Assets.xcassets/Splash.imageset/` に `splash-2732x2732` で始まる画像が残っていたら消してください（プロジェクトを作り直した直後だけ残る、使われない雛形の画像です）。
